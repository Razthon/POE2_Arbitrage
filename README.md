Program that is able to pull multiple values of different items in the game Path of Exile 2. The program will then run a number of calculations to determine profitable trades of items through arbitrage calculations. 

Multiple variables are loaded into a module that will send a large number of API calls comparing values of specified items to one another (Call for rate for a --> b, b --> c, c --> a) to calculate the most optimal way to make profit from trading in Path of Exile 2.

Currently "unfinished" as I was not able to implement all the currency items in the game but the main program will still calculate and display the rates for trading 7 different items with many different combinations and showing a rate of profit as well as trade volume.


Limitations and room for future improvements:

Currently the project is not optimized for practical use mainly due to API key limits and processing time

Ideally more currencies would be added for trading but basic level currencies are included
